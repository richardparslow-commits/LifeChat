# Condition-coverage candidate phrases
#
# The corpus the 2026-09-19 questionnaire sweep was measured against: 237
# phrases a carrier medical-history questionnaire enumerates, written down
# before any of them were mapped, so the measurement could not be fitted to the
# answer. It is now the standing regression corpus for the sweep tool:
#
#   npm run conditions:sweep
#
# Every row must be either mapped to a canonical condition or classified as
# health data by the gate. Rows that are neither are the work queue; rows that
# are gated but uncoded are a policy decision and are listed for inspection.
#
# The closure ledger for the *boundary probes* (including the rows this sweep
# surfaced and the descriptive reasons for the uncoded ones) lives in
# tests/medical-condition-gate.test.ts — this file is the input corpus, not the
# authority on scope.
#
# Format: one phrase per line, `#` comments and blank lines ignored, or a JSON
# array of strings. Replace or extend the file to measure a new source, then run
# the sweep; the same measurement is what turns findings into batches.
